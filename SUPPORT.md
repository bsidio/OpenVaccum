# OpenVacuum Support

OpenVacuum controls robot vacuums running Valetudo over your home network. It's an unofficial app, so please report app problems here, not to the Valetudo project.

**Get help or report a bug:** https://github.com/bsidio/valetudo-ios/issues
Please include your iPhone model, iOS version, robot model and Valetudo version (Settings > System Information).

**Common fixes**
- Robot not found: make sure your iPhone is on the same Wi-Fi as the robot and that Local Network access is on for OpenVacuum in Settings > Privacy & Security > Local Network. You can also type the robot's IP address.
- Controls missing: the app only shows what your robot and Valetudo version support.
- Camera not shown: the app can't turn the camera on. Camera streaming must be turned on in Valetudo's web interface first.
- Installing Valetudo: see https://valetudo.cloud. The app doesn't install it.

**Privacy:** OpenVacuum collects no data. See [PRIVACY.md](PRIVACY.md).
